### Architecture gaps to fill (priority order)

**1. Model Gateway — implement the adapters** (biggest unblock)
The interface is clean. You need concrete adapters:

```typescript
// packages/model-gateway/src/adapters/ollama.ts
import type { ModelAdapter, ModelRequest, ModelResponse } from '../index'

export class OllamaAdapter implements ModelAdapter {
  provider = 'ollama' as const
  constructor(private baseUrl = 'http://localhost:11434') {}

  async complete(req: ModelRequest): Promise<ModelResponse> {
    const res = await fetch(`${this.baseUrl}/api/chat`, {
      method: 'POST',
      body: JSON.stringify({
        model: req.model,
        messages: req.messages,
        stream: false,
        options: { temperature: req.temperature ?? 0.3 },
      }),
    })
    const data = await res.json()
    return {
      id: crypto.randomUUID(),
      provider: 'ollama',
      model: req.model,
      content: data.message.content,
      finishReason: data.done ? 'stop' : 'length',
      usage: {
        inputTokens: data.prompt_eval_count ?? 0,
        outputTokens: data.eval_count ?? 0,
        totalTokens: (data.prompt_eval_count ?? 0) + (data.eval_count ?? 0),
      },
    }
  }

  async *stream(req: ModelRequest) { /* SSE from /api/chat?stream=true */ }
  async listModels() { /* GET /api/tags */ }
  async health() { /* GET /api/version */ }
}
```

### Key design decision to make now

The PDF doc mentions **model flexibility** (local vs cloud). Your `ModelGateway` interface supports this cleanly. You need a **routing policy** per agent — e.g.:

```typescript
// In ai.agents.model_policy jsonb column
{
  "preferred": "ollama/llama3.2",
  "fallback": "anthropic/claude-haiku-4-5",
  "localOnly": false,
  "maxCostCentsPerRun": 5
}
```

This lets users toggle "private mode" (local only) vs "fast mode" (cloud) without changing agent logic.
